What this is

A working mini-ERP for Wasatch Board Co., a fictional Utah skateboard company, built for GSCM 401. It covers selling, inventory, purchasing, light manufacturing, planning and financial reporting across three locations.

How it was built

  • AI tools: the code and database design were written with Claude Code (Anthropic), directed and reviewed by the team from a written specification.
  • Database, logins and realtime: Supabase (a hosted PostgreSQL database). Business rules such as posting a sale or receiving a purchase order run inside the database as functions, so each transaction fully happens or not at all.
  • Front end: plain HTML, CSS and JavaScript with no framework and no build step.
  • Hosting: GitHub Pages, served from a public GitHub repository.

How the numbers work

  • One inventory ledger. Every sale, receipt, transfer, build, return and adjustment is a row in a single movements table. On-hand quantity is the sum of that ledger.
  • Everything is calculated. Costs, totals and metrics are computed from stored transactions, so changing an input changes every result that depends on it.
  • Weighted average cost. Each item's cost is re-averaged every time stock is received. A complete board's cost is rolled up from its components.
  • Security. Database row-level security decides what each login can read or change.
